# Личный гардероб

Мобильное PWA на русском по [спецификации](docs/wardrobe-mvp-spec.md): 70 вещей и 150 сочетаний. Статическое приложение на HTML, CSS и JavaScript; серверное приложение не требуется.

## Запуск и проверка

Нужны Python3 и Node.js22+.

```sh
npm start
```

Открыть [локальный сайт](http://127.0.0.1:5173/). Для ES modules и IndexedDB нужен HTTP.

```sh
npm ci
npx playwright install chromium
npm run check
```

Вместо скачивания Chromium можно использовать установленный Chrome:

```sh
PW_BROWSER_CHANNEL=chrome npm run check
```

`npm run check` проверяет бизнес-логику, собирает `dist/` и запускает браузерные проверки production-сборки. Перед проверкой остановить `npm start`, чтобы освободить порт5173. PWA-тесты выполняются на сборке; source-only `npm run test:e2e` их пропускает.

## Подбор и гардероб

- Выбрать обязательную вещь, сезон и повод. Минимум три разных набора одежды для каждой вещи в целом; сезон и повод сужают выдачу. Замена одних аксессуаров не считается новым набором одежды.
- Сезон выбирается компактной кнопкой справа в шапке и сохраняется на устройстве. Запросов погоды и геолокации нет.
- Гардероб разбит на категории: футболки, топы, лонгсливы, рубашки и блузы, свитера, кофты, толстовки, жилеты, жакеты и куртки, шорты, джинсы, брюки, юбки, платья.
- В ленте — готовые лукбуки с аксессуарами. В «Подробнее» — визуализация, оригинальные фотографии и список «Чего не хватает». Предлагаемые дополнения отмечены «Вне каталога».
- Добавление фото отключено. Уже сохранённые на устройстве фото доступны только для просмотра в отдельной категории; приложение не удаляет эти записи.
- Сезонная разметка не устанавливает состав ткани или точную теплоту по фотографии. Зимние варианты с недостающей верхней одеждой явно перечисляют её среди дополнений.

## Установка и офлайн

На сайте есть кнопка «Добавить на главный экран».

- iPhone/iPad: Safari → «Поделиться» → «На экран „Домой“» → «Добавить».
- Android: кнопка на сайте либо меню Chrome → «Установить приложение» / «Добавить на главный экран».
- Компьютер: значок установки в Chrome/Edge или установка через меню браузера.

После первого открытия с интернетом оболочка и каталог доступны офлайн; изображения кешируются по мере просмотра. Все фотографии заранее не скачиваются. Обновление запускается кнопкой «Обновить приложение» и не очищает настройки, старые пользовательские фото или кеши других приложений. PWA-id `/beauty_app/` отделён от Gym на том же домене.

Синхронизации и резервных копий нет. Очистка данных браузера может удалить настройки и сохранённые ранее фото. Исходный каталог и лукбуки публичны.

## GitHub Pages

Сайт: https://ivan-karavan.github.io/beauty_app/.

Push в `main` запускает `.github/workflows/deploy.yml`: unit-тесты → сборка → production browser tests → публикация `dist/`. Источник в Settings → Pages — GitHub Actions. Незавершённые контрольные коммиты не отправлять до полного прогона проверок.

Для другого HTTPS-хостинга выполнить `npm run build` и разместить всю папку `dist/`. Она содержит только runtime-файлы, каталог и используемые изображения; тесты, документация и промпты в публикацию не входят.

## Изображения

Лукбуки подготовлены встроенным `image_gen` и лежат в `looks/previews/`; сайт не отправляет фотографии на генерацию. Первые промпты — `looks/lookbook-prompts.json`, сезонное расширение — `looks/seasonal-lookbook-prompts.json`. Иконки PWA — `icons/`, исходник — `icons/icon.svg`.
