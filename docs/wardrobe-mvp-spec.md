# Личный гардероб — MVP

Мобильный сайт на русском для одной пользовательницы. Основная функция — предложения образов из текущего гардероба.

## Образы

- Пользовательница выбирает одну вещь как обязательную основу и повод: повседневный или вечерний.
- Погода загружается автоматически из бесплатного сервиса. При сбое доступна кнопка «Выбрать погоду» для ручного ввода.
- Подходящие готовые сочетания показываются вертикальной лентой. При изменении основы, повода или погоды лента обновляется.
- Для повседневного приоритет — комфорт и свобода движений. Для вечернего — гармоничное сочетание и дополнение вещей. Неизвестные свойства одежды не выдаются за установленные.
- В карточке — готовый коллаж выбранного сочетания, если он есть; иначе отдельные фотографии этих вещей. По нажатию открываются подробности.
- Все образы состоят только из текущих вещей. Если подходящих сочетаний нет, показать сообщение.

## Гардероб

- Сетка текущих вещей и новых фотографий. Фильтры: «Все», «В подборе», «Новые фото».
- Карточка текущей вещи содержит фото, название и действие «Образы с этой вещью». Оно выбирает вещь основой и открывает ленту.
- Новые фотографии помечены «Пока без подбора» и доступны для просмотра крупно.
- Текущий каталог и готовые сочетания доступны сразу, без повторной загрузки фотографий.

## Добавление фото

- Компактная кнопка «Добавить фото» расположена сверху. Внизу — навигация «Образы» и «Гардероб».
- Выбор фото с телефона или камеры → предпросмотр → сохранение в гардероб.
- Фотографии сохраняются на устройстве и остаются после перезагрузки страницы. При ошибке показывается сообщение.
- Распознавание новых фото и создание образов из них отложены на следующую итерацию.

## Хранение и ограничения

- Исходный каталог, фотографии и готовые сочетания публикуются на GitHub Pages. Новые добавленные фото сохраняются только на устройстве и на сервер не отправляются. Платных сервисов нет.
- Внешние запросы разрешены для погоды, без передачи гардероба.
- Синхронизации и резервного копирования нет. Очистка данных браузера может удалить загруженные фото.
- Автоматическое создание коллажей не требуется.
